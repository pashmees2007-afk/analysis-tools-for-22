# Dry-Run Image Source

The no-UI dry run will use an independently sourced Mars surface image from the NASA Curiosity mission.

| Field | Value |
|---|---|
| Title | *Raw, Natural, and White-Balanced Views of Martian Terrain* |
| Source image record | [NASA Science](https://science.nasa.gov/resource/raw-natural-and-white-balanced-views-of-martian-terrain/) |
| Cross-check record | [NASA Jet Propulsion Laboratory](https://www.jpl.nasa.gov/images/pia16800-raw-natural-and-white-balanced-views-of-martian-terrain/) |
| Instrument | Curiosity Mast Camera (Mastcam) |
| Scene | Curiosity Sol 19, looking south-southwest from the landing site toward Mount Sharp |
| Credit | NASA/JPL-Caltech/MSSS |

The NASA and JPL records identify this as a real Mars terrain scene. The test uses only the terrain portion of the published three-panel image rather than the composite labels or panel borders.
